# EvalKit Synthetic Multi-Turn Tutorial Data

This directory contains synthetic tutorial data for exercising EvalKit workflows. It is not expert-authored, not human-validated, and not a benchmark.

The examples cover generic eval workflow failure categories such as instruction drift, context loss, hallucinated tool output, conflicting constraints, format drift, evidence misuse, over-broad answer style, and inconsistent claims. They avoid safety/refusal benchmark framing.
